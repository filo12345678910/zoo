# Zoo Project

A project developed as part of the Object-Oriented Programming course. It features a console-based interface for managing a virtual zoo.

## How to Use

Compile and run `zoo.cpp`. Enter one of the following numbers in the console and follow the instructions:

1. **Breed animals** – Simulates animal reproduction until the zoo population reaches 100 animals.
2. **Clear the zoo** – Removes all animals from the zoo.
3. **Add animals** – Adds a specified number of animals to the zoo.
4. **Show animals** – Displays all animals currently in the zoo.

## Technologies

- C++
- Object-Oriented Programming
